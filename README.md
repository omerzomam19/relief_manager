# نظام إدارة المساعدات الإغاثية / Relief Aid Manager

Flask + ملفات JSON فقط (بدون قاعدة بيانات). واجهة عربية/إنجليزية (RTL/LTR) ووضع ليلي/نهاري.

## التشغيل
```bash
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
افتح http://127.0.0.1:5000

## بيانات الدخول الافتراضية
- المدير: `admin` / `admin123`
- الموظف: `staff` / `staff123`

غيّر هذه الحسابات قبل أي استخدام فعلي (أنشئ مديراً جديداً من صفحة المستخدمين ثم احذف الافتراضيين).

## البيانات التجريبية
عند أول تشغيل فقط تُنشأ بيانات تجريبية: 10 مواد، 8 مستفيدين، 15 عملية توزيع (مع مواد منخفضة ونافدة لعرض التنبيهات).
لبدء نظيف: أوقف التطبيق، احذف ملفات `data/*.json`، ثم اجعل الدالة `_seed()` في `storage.py` لا تُستدعى (احذف السطرين الأخيرين من `init_storage`).

## متغيرات البيئة
`SECRET_KEY` (يُولَّد عشوائياً إن لم يُحدد)، `HOST`، `PORT`، `FLASK_DEBUG=1` للتطوير فقط.

## الصلاحيات
admin: كل شيء. staff: عرض وإضافة وتعديل وتوزيع، بدون حذف.
